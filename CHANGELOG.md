# Changelog

All notable changes to Quantum Bridge will be documented in this file.

The format follows Keep a Changelog, and this project uses semantic versioning.

## [0.1.0] - 2026-06-01

### Added

- Initial Python package scaffold.
- Provider-neutral bridge client and resource specification models.
- Dependency-free local OpenQASM 2 simulator provider.
- `quantum-bridge` and `qb` CLI commands.
- Local JSON job result store.
- Bell-state example circuit.
- CI and GitHub release workflows.
- Demo quantum algorithm catalog with speedup focus, constraints, payload hints, and references.
- Demo migration advisor for project computation sessions.
- Local demo HTTP API for `/algorithms`, `/demo`, and `/advise`.
- Platform credential prompts for IBM Quantum, AWS Braket, Azure Quantum, and D-Wave Leap.
